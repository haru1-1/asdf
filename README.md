# 삼국지 : 천하의 서막 (전체 이미지 적용판)

브라우저에서 API 키나 외부 서버 없이 바로 실행할 수 있는 삼국지 턴제 전략 게임입니다.
성 3D 디오라마 배경 6종, 전투 지역 배경 3종, 군주·장수·병사·백성 일러스트 10종(총 19종)이 모두 적용되어 있습니다.

## 폴더 및 파일 구성
- `index.html`: 메인 화면, 튜토리얼·전투·엔딩 모달
- `style.css`: 어두운 남색·금색 테마, 3D 디오라마 연출, 원형 금테 인물 토큰, PC/모바일 반응형
- `assets.js`: `images/` 폴더의 19종 이미지 경로 연결 설정
- `audio.js`: 배경음악 및 버튼·전투 효과음 제어 (Web Audio 기본 내장 + 외부 음원 연결 가능)
- `game.js`: 턴 진행, 내정, 외교, 연구 트리, 전투 계산, AI, 자동 저장
- `images/`: 성 6종, 전장 3종, 인물 10종 이미지 파일

## GitHub Pages 배포 방법
1. 압축을 푼 모든 파일과 `images` 폴더를 GitHub 저장소 최상위(root)에 그대로 업로드합니다.
2. 저장소의 **Settings > Pages**에서 Branch를 `main` / `/ (root)`로 설정하고 저장합니다.
3. 잠시 후 생성되는 주소로 PC와 모바일에서 바로 접속할 수 있습니다.
